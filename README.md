# 🧱 물체의 운동을 방해하는 힘 실험실

중학교 1학년 과학 「Ⅴ. 힘의 작용」 — **마찰력**.
학습 목표 **마찰력의 크기와 방향을 설명할 수 있다.**

## 어떻게 여나

**설치할 것이 없습니다.** `index.html` 을 더블클릭하면 바로 열립니다.

| 화면 | 파일 | 하는 일 |
|---|---|---|
| 🧱 실험실 | `index.html` | 블록을 당겨 보고, 무엇이 마찰력을 정하는지 확인한다 |
| 📝 학습지 | `worksheet.html` | 15문항 (12문항 자동 채점) · 종이로도 뽑을 수 있다 |
| 🔑 정답지 | `worksheet.html?key` | 정답만 A4 **한 쪽**. 선생님용 화면에서 들어간다 |
| 🗂️ 선생님용 | `teacher.html` | 제출한 PDF 를 파일 이름만 읽어 정리한다 |

## 무엇을 보여 주나

- **🧱 당겨 보기** — 용수철저울로 천천히 당겨 보세요.
  **당기는 힘 화살표와 마찰력 화살표가 언제나 같은 길이**로 함께 자랍니다.
  한계에 닿으면 마찰력만 멈추고 블록이 미끄러지기 시작해요.
- **📊 무엇이 정할까** — 접촉면 3가지 × 상자 3가지의 **한계**를 한 화면에 늘어놓습니다.
- **⛰️ 빗면에서** — 내려갈 때와 끌어올릴 때 마찰력의 **방향이 뒤집힙니다.**

## 이 앱이 남기고 싶은 한 문장

> **마찰력에는 스스로 정해진 크기가 없다 — 내가 당기는 만큼 따라 커진다.**
> 다만 **한계**까지만. 그 한계는 무게와 접촉면이 정한다.

그래서 움직이지 않을 때는 **용수철저울의 눈금이 곧 마찰력**입니다.

## 인쇄

학습지를 열고 `Ctrl+P` — **A4 두 쪽**(실제로 인쇄해서 확인했습니다).
